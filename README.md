A one-line entry for the make.fun "Ship It Friday" bounty: a Python program
that writes a single git commit message — the one an AI coding agent leaves
behind in the last minute before a Friday deploy breaks production — to
`/output/entry.txt`.

Run it with `python3 main.py` (set `MAKEFUN_OUTPUT_DIR` to change where
`entry.txt` lands).
